# Kanban Board with Dashboard

## Project Description

A React JS web application implementing a Kanban Board with Dashboard functionality, featuring task management, category management, and data persistence using Local Storage.

### Features

**Kanban Board Page**
- 3-column layout: TO DO, DOING, DONE
- Create, edit, and delete tasks
- Move tasks between columns
- Assign responsible persons and categories to tasks
- Set start dates, due dates, and complete dates
- Category management (select existing or add new)

**Dashboard Page**
- Summary cards showing total tasks, TO DO, DOING, DONE, and overdue counts
- Task Status Chart (Pie chart)
- Task Category Chart (Bar chart)
- Completion Performance Chart (Early/On Time/Late)

**Data Persistence**
- All task and category data stored in Local Storage
- Data persists across page refreshes

### Usage Instructions

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Access the application at `http://localhost:5173`
5. Use the Kanban Board to manage tasks
6. Navigate to the Dashboard to view summaries and charts
